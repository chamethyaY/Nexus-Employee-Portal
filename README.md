# Employee Management System (Java OOP, Spring Boot, Thymeleaf)

## Overview
The Employee Management System is a full-stack web application built using **Java**, **Spring Boot**, and **Thymeleaf**. It allows organizations to efficiently manage employee records with **CRUD operations** and provides an interactive, dynamic interface for user interaction.

This project demonstrates the application of **Java OOP principles**, **Spring Boot backend development**, and **Thymeleaf front-end integration**.

---

## Features
- **Employee CRUD Operations**:
  - Create, Read, Update, and Delete employee records.
  - Efficient data management using **Spring Data JPA** and **Java Collections**.
  
- **Java OOP Principles**:
  - Encapsulation, Inheritance, Polymorphism, and Abstraction applied in service and model layers.
  
- **Spring Boot Backend**:
  - Modular and maintainable architecture using **Controllers**, **Services**, and **Repositories**.
  
- **Thymeleaf Frontend**:
  - Interactive web pages with:
    - Dynamic content rendering
    - Conditional rendering
    - Loops
    - Data binding between front-end and back-end
    - Client-side validation using JavaScript

- **User-Friendly Interface**:
  - Easy navigation and responsive UI for managing employee data.

---

## Technology Stack
- **Backend**: Java, Spring Boot, Spring Data JPA
- **Frontend**: Thymeleaf, HTML, CSS, JavaScript
- **Database**: H2 / MySQL (can be swapped)
- **Build Tool**: Maven
- **Server**: Embedded Tomcat (via Spring Boot)
